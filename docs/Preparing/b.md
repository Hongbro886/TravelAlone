## 火车

### 购票软件

::: tip

订购火车票，建议使用“铁路12306”APP

::: info

“铁路12306” 是 相关领域官方软件

:::

### 购票信息

购买火车票时需要注意以下信息，这些信息是必要的。

- 车次号

- 你的出发站

- 你的到达站

- 你的座位等级

::: info

购买火车票的过程是十分简单的，如果没有APP账号，你需要在购票前进行注册。

:::

::: tip
如果您未满14周岁，这里有一个非正规技巧

**购票带成年人，随后将成年人票退票，即可单独乘车**
:::

### 购票时间

开票时间为**发车时间前14天北京时间8:30**

::: warning

热门时间，热门车次可能需要卡点抢票

:::
