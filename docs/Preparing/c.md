## 通讯设备与电量管理

因为独自出行的性质，一部时时刻刻都有电的设备是非常必要的

::: info 核心原则

永远让你的设备电量大于**20%**

:::

### 你需要准备的硬件设备是

- 一部手机

- 一块充电宝  容量要求：**10000mAh <= 电池容量**
  ::: tip 如果你坐飞机
  **电池容量 < 100Wh**
  :::

- 电源适配器

- 充电线

### 活动控制暨电量保持

我们建议，即使你选择了最自由的出行方式，你仍然且唯一需要注意的就是你的手机电量

## 软件

去到陌生城市，一些旅行软件是必备的

- 地图软件
  ::: tip
  通常来说，如果你选择“高德地图”，你将会获得**最详细的公共交通指引和实时数据更新**
  :::

- 打车软件
  ::: warning 一个忠告
  不同地区的司机，更习惯使用的打车平台各不一样，根据简单经验统计，东部沿海城市，“高德地图”作为打车软件已经开始流行，但在中部城市，“嘀嘀打车”依然是唯一选择
  ::: danger 以及……
  我们**非常不建议**你使用专有平台进行打车，这通常极不通用即使花费更少
  :::

## 衣物

### 数量

衣物的数量可以根据平时的换洗节奏进行选择，但是注意你需要有地方存放这些干净的以及脏的衣物
::: tip
可以尝试在旅途中某一个停留时间较长且条件允许的酒店使用**洗衣设施**，如果你不会，那就去问前台

:::

### 类型

根据目标地点的天气状况选择衣物，我们建议使用手机自带的天气软件进行查询，通常这些软件里会有穿衣建议

## 身份证

::: danger 必须！

**请务必携带你的身份证**否则你将可能无法入住任何酒店以及乘坐任何远途交通工具

:::

::: warning 警告
确保你的身份证是**二代身份证（这对于2005年以后出生的人通常是必然的）** 且**未过期（在背面的底部“有效期限“查看）**

:::
**带好你的身份证**

## 水

对于我们的主要游玩方式：CityWalk来说，一杯水是必要的

你可以从酒店带一杯矿泉水，我们不建议自带水杯，因为那可能比较重
