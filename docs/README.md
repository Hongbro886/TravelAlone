## 这份文档是什么

这份文档是写给中国青少年的一份独自出行指南，我们希望更多的青少年能在这篇文档的指引下，安全、勇敢地独自出行，提升自己在现实中的问题处置能力、独立能力和语言表达与交流能力。

## 这份文档是写给谁的

这份文档是写给那些有独自出行想法的人。

## 核心原则

在任何时候，未成年人的出行都必须在其法定监护人的允许的情况下进行，本文档也只会讲述在法定监护人允许的情况下进行出行的技巧和方法。

我们将在坚决站在中国法律一方，站在正义一方，站在法定监护人一方，站在保护未成年人身心健康的一方的情况下编写这份文档。
